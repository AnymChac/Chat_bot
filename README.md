## 📝 Descripción
Este proyecto consiste en la creación de un ChatBot funcional basado en lógica de programación con JavaScript. El objetivo fue desarrollar un sistema capaz de interpretar entradas de texto del usuario y proporcionar respuestas automáticas coherentes, simulando una interacción básica de asistencia o conversación.

Es un excelente ejemplo de cómo manejar estructuras de control, filtrado de palabras clave y manipulación del DOM para crear interfaces interactivas.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** JavaScript (ES6+).
- **Interfaz:** HTML5 y CSS3 para el diseño de la ventana de chat.
- **Lógica:** Estructuras condicionales y procesamiento de strings para la interpretación de mensajes.

## 📖 Ejemplos de Uso

**Interacción por Palabras Clave**
- El bot está programado para reconocer patrones en los mensajes. Por ejemplo: Si escribes "Hola", el bot responderá con un saludo personalizado. Si pides "Ayuda", el bot listará las opciones o comandos que puede ejecutar.

**Procesamiento de Respuestas**
- El sistema analiza la entrada del usuario, la convierte a minúsculas para evitar errores de coincidencia (case sensitivity) y busca dentro de su lógica interna la respuesta más adecuada, demostrando un flujo de control limpio.

**Simulación de Escritura**
- Para mejorar la experiencia de usuario (UX), el chat simula un pequeño tiempo de respuesta, haciendo que la interacción se sienta más natural y menos mecánica.
